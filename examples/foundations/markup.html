FAQ

Is this example canonical?

No. CRFT.md, docs/**, and styles/** win every conflict. Fix or retire the example when it drifts.

Where do product rules go?

Outside the adopted crft tree, in the project’s normal CSS owner. This specimen uses @layer project. An accidental unlayered rule outranks every named layer.

May I use data-theme?

Use data-theme="invert|tone|accent" for colors only. Set root color-scheme for light or dark.
