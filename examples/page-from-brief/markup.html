Ship structure without a component tax.

crft is a finite CSS system—tokens, type, layout, themes—not a library of product widgets. Copy once, keep ownership obvious, migrate one visible slice at a time.

Ownership ladder

  2. Second Public crft API confirmed in the handbook and CSS.
  3. Third Distinctive chrome in project-owned CSS. This specimen uses @layer project; crft does not require that owner.

What this page will not sell you

Warning: if a vendor pitch needs these, it is not crft.

  • A component registry or “hero” primitive as shared API.
  • Invented dark schemes or palette names as data-accent routes.
  • Accidental unlayered utilities that silently outrank the system.
  • Framework adapters shipped inside the CSS snapshot.

Before you copy

Does copy overwrite our CSS?

No. Copy vendors a snapshot and refuses targets that already exist. Legacy sheets stay until you migrate slice by slice.

Where do our buttons and cards go?

In product markup and project-owned CSS. .btn, .crd, and .lnk are project component naming conventions. crft does not style them.

How do we know the brief was honored?

One primary action, three signature moves visible without CSS, and every layout claim labeled observed, inferred, or unknown.
