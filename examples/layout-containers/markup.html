Container measures

Narrow: .c.sm

Two-thirds of the default maximum. The dashed outline marks the container edge; paragraph measure can stop before that edge.

Default: .c

The default maximum comes from the current content-max token. Automatic inline margins center the box without centering its text.

Wide: .c.lg

Four-thirds of the default maximum. All three boxes share the same available width until there is enough room for a maximum to take effect.
